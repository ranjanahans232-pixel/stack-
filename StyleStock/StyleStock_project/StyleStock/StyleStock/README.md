StyleStock — Clothing Inventory Management System
Project Overview
StyleStock is a web-based inventory management system designed to help clothing businesses manage products, brands, warehouses, and stock distribution. The application allows authorized staff to maintain product information, monitor inventory quantities, and transfer products between distribution centres.
Problem Statement
Businesses that manage clothing inventory across multiple locations may have difficulty tracking available stock, identifying low-stock products, and monitoring inventory transfers. StyleStock aims to organize this information in one application and make inventory management easier.
Project Motivation
Our group chose this project because inventory management is a practical business problem. It provides opportunities to learn Spring Boot, Spring MVC, Thymeleaf, relational databases, JPA, validation, and Spring Security while building useful CRUD functionality.
Main Features
•	View, create, update, and manage products.
•	Organize products by brand and category.
•	Manage multiple distribution centres.
•	Track stock quantities at each location.
•	Record inventory transfers between locations.
•	Manage staff login and role-based permissions.
Technology Stack
•	Java and Spring Boot
•	Spring Web / Spring MVC
•	Thymeleaf
•	Spring Data JPA
•	Spring Security
•	Spring Data REST
•	Jakarta Bean Validation
•	Lombok
